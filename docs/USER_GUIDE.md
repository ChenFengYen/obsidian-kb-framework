# 使用者日常操作指南

## 開始一次對話

啟動 AI 代理後，它會自動：
1. 讀取知識庫進度
2. 報告目前狀態
3. 詢問你本次目標

你可以直接說「繼續」讓 AI 接續上次進度。

## 日常操作

### 學習新概念（問題驅動模式）

直接問 AI 任何問題：
- 「什麼是 X？」
- 「X 和 Y 有什麼關係？」
- 「如何把 X 應用在我的研究中？」

AI 會搜尋知識庫回答。如果發現知識缺口，會建議建立新筆記。

### 入庫新資料

```
/onboard [筆記名稱]
```

AI 會自動：連結注入 → 概念發現 → 報告結果。

### 檢查知識庫狀態

```
/review-vault
```

AI 分析知識庫結構，給出優先行動建議。

### 不知道下一步？

```
/suggest-next
```

AI 根據你的學習目標推薦最有價值的行動。

### 結束對話

說「暫停」或「結束」，AI 會：
1. 回顧對話中的洞見
2. 建議哪些內容可以寫入筆記
3. 更新進度記錄

## Obsidian 操作

### QuickAdd 快速建立概念筆記

安裝 QuickAdd 插件後：
1. 閱讀筆記時選取術語
2. 按 `Ctrl+Shift+N`
3. 選擇領域 → 自動建立 stub 筆記

### 查看反向連結

點擊概念筆記，查看右側面板的「反向連結」— 這顯示哪些其他筆記引用了它。

## 指令速查

| 指令 | 用途 |
|:--|:--|
| `/init-domain` | 首次設定：AI 引導建庫 |
| `/review-vault` | 架構診斷 + 行動建議 |
| `/suggest-next` | 學習路徑推薦 |
| `/debrief` | 手動觸發知識回收 |
| `/enrich` | 批量充實薄弱筆記 |
| `/onboard [name]` | 新筆記入庫 |
| `/pipeline-status` | 查看建設進度 |
| `/process-inbox` | 處理 QuickAdd 佇列 |
