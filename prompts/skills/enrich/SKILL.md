# 批量充實筆記

## 任務

讀取指定的任務檔並逐一充實其中的薄弱筆記。

## 步驟

1. **定位任務檔**：在 `OV-Papers/enrich-tasks/` 中尋找匹配 `$ARGUMENTS` 的任務檔
   - 若參數是完整檔名（如 `enrich_batch_physio_batch01_20260310.md`），直接讀取
   - 若參數是關鍵字（如 `physio_batch01`），模糊匹配目錄中的檔案

2. **讀取任務檔**：理解每個待充實筆記的：
   - 目標筆記路徑
   - 目前內容（thin/stub 狀態）
   - 來源論文段落摘錄
   - 風格參考範例

3. **逐一充實筆記**（按任務檔中的順序）：
   - 先讀取目標筆記的現有內容
   - 讀取來源論文的**完整內容**（不僅依賴任務檔摘錄）
   - 按 LYT 格式結構化筆記，包含：定義、核心概念、研究應用、相關筆記、待解決問題
   - 在筆記開頭加入 `<!-- AI-ENRICHED - NEEDS REVIEW -->` 標記
   - 使用 `[[citekey]]` 格式連結論文（不用 alias）
   - 主動建立與現有概念筆記的內部連結

4. **每完成一篇**，報告：
   - 筆記名稱
   - 充實前後行數對比
   - 新增的連結數量

5. **全部完成後**，輸出摘要：
   - 完成/跳過的筆記數量
   - 需要注意的問題（如來源論文不足、概念重疊等）

## 注意事項

- 偏好植物生理學術語的深度解釋（使用者知識缺口）
- 概念筆記應具原子性：一個概念一份筆記
- 若筆記已有 ≥30 行內容，視為已充實，跳過並通知
- 每個區段都要有實質內容才算「充實」
