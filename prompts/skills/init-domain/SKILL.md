# 初始化知識庫

## 任務

透過對話引導使用者建立知識庫的領域結構。適合不熟悉 LYT 或知識架構方法的新手。

## 步驟

### Phase 1：了解使用者

1. 詢問使用者的研究/學習領域（可以是多個）
2. 詢問目前最想深入的方向（current_focus）
3. 詢問自評經驗等級：
   - 初學者（beginner）：需要 AI 多解釋概念和結構
   - 中級（intermediate）：有基本知識，想系統化
   - 進階（advanced）：已有深度，想建立完整知識網路

### Phase 2：建議領域分類

根據使用者描述，建議 3-8 個領域分類（將成為 OV-* 資料夾）：
- 每個領域給出名稱和簡短描述
- 建議相關的關鍵字（用於自動路由）
- 向使用者解釋：「這些分類不是死板的資料夾，而是知識的大區塊。筆記之間的連結會跨越這些分類。」

**等使用者確認或調整後再繼續。**

### Phase 3：建議 MOC 結構

為每個領域建議一個 MOC（內容地圖）：
- 簡要解釋 MOC 是什麼（用使用者的領域舉例）
- 說明 MOC 不是連結清單，而是「你對這個領域的理解地圖」
- 初始 MOC 可以只有標題和 2-3 個子分組

### Phase 4：生成配置

確認後，執行：

1. 生成 `vault_config.yaml`（填入領域、關鍵字、學習目標、經驗等級）
2. 建立目錄結構：每個領域一個 `OV-{name}/Map/`、`OV-{name}/Note/`、`OV-{name}/Pic/`
3. 建立 `OV-Papers/` 及子目錄（PDF-md、PDF-raw、PDF-assets、scripts、enrich-tasks）
4. 生成 `Home.md`（首頁，連結到所有 MOC）
5. 為每個領域建立空白 MOC 檔案（含開頭敘述提示）
6. 複製 framework/ 腳本到 `OV-Papers/scripts/`

### Phase 5：說明下一步

告訴使用者：
- 「你的知識庫已建好基礎結構。現在你可以開始加入筆記。」
- 說明問題驅動模式：「有任何問題就直接問我，我會搜尋知識庫回答，發現缺口時提議建立新筆記。」
- 說明 QuickAdd：「安裝 QuickAdd 插件後，閱讀時可以快速圈選術語建立概念筆記。」

## 注意事項

- 用使用者的領域語言舉例，不要用抽象的方法論術語
- beginner 使用者：多解釋 LYT 概念（MOC、原子筆記、連結哲學）
- advanced 使用者：簡潔說明，快速完成設定
- 不要一次給太多資訊——分階段引導
